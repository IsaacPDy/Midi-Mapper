# MIDI Mapper

[**Download MIDI Mapper for macOS (Apple Silicon)**](https://github.com/IsaacPDy/Midi-Mapper/releases/latest/download/MIDI-Mapper-macOS-arm64.zip)

Unzip the download, move **MIDI Mapper.app** to Applications, and double-click to open. Requires macOS 11 or later. No developer tools are needed.

If macOS blocks the app because it is not notarized, use **System Settings → Privacy & Security → Open Anyway**. Enable **MIDI Mapper** under **Privacy & Security → Accessibility** to let it send keyboard shortcuts.
